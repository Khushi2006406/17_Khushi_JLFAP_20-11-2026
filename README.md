# 17_Khushi_JLFAP_20-11-2026
About the Project
This repository contains practical implementations of Formal Languages and Automata Theory using JFLAP software.
JFLAP is used to construct, test, simulate and convert different types of automata and formal grammars.
Experiments Performed
Deterministic Finite Automata (DFA)
Nondeterministic Finite Automata (NFA)
NFA to DFA Conversion
DFA Minimization
Files Included
Each experiment contains:
JFLAP .jff file
Practical diagram screenshots (.png)
Software Requirements
JFLAP
Java Runtime Environment (JRE)
Purpose
To understand and visualize automata construction, state transitions, conversion and minimization using JFLAP.
